# Chat-Application-using-TCP-Sockets-Client-Server-Model-
Project Title:
Chat Application using TCP Sockets (Client-Server Model)

 Project Description:
A terminal-based chat application built using TCP socket programming. It allows multiple clients to connect to a server and exchange messages in real time. This showcases basic networking principles including sockets, multithreading, and data transmission over TCP.

🛠 Tech Stack:
Programming Language: Python

Concepts Used: Sockets, Threads, TCP protocol

Project Structure:

chat-app/
├── README.md
├── server.py
└── client.py

How to Run:
Open two terminals.

Run python server.py in one terminal.

Run python client.py in the second terminal (repeat for multiple clients).

Chat between clients in real time.
